# GitHub steps for Assignment 3 (at least one commit per task - commit as you finish each one)

1. Fill in your name and register number in `README.md` and at the top of `build_report.py` (NAME, REGNO, REPO).
2. Create an EMPTY GitHub repository `CSA08-<RegisterNumber>-Assignment3` (add the faculty as collaborators or make it public).
3. In the unzipped folder:

```
git init && git branch -M main
git remote add origin https://github.com/<username>/CSA08-<RegisterNumber>-Assignment3.git
git add Task01 && git commit -m "Task01: rainfall lists, slicing, moving average methods"
git add Task02 && git commit -m "Task02: tuples, aliasing, shallow/deep copy, dictionary grid"
git add Task03 && git commit -m "Task03: complaint word counts with dict, Counter, list.count"
git add Task04 && git commit -m "Task04: elective clashes with set operations"
git add Task05 && git commit -m "Task05: sensor cleaning with comprehensions, map/filter, generators"
git add Task06 && git commit -m "Task06: railway timetable nested data and station index"
git add Task07 && git commit -m "Task07: contact merging design with dictionary and union-find"
git add README.md requirements.txt run_all.py capture_outputs.py build_report.py .gitignore Assignment3_Report.* && git commit -m "Add README, report and helper scripts"
git push -u origin main
```
4. Put the repository link on the report's title page and submit the PDF.
