slices are NEW lists (copies of references): True | readings unchanged: 365

=== Derived number of additions (window w = 7, n readings) ===
naive  : (n - w + 1) windows x (w - 1) additions = 6(n - 6)   [7(n-6) if the sum starts from 0 -> O(7n)]
running: (w - 1) + 2(n - w) = 2n - 8 operations (one add + one subtract per slide) -> O(n)

=== Design question: a reading arrives late and must be inserted at its date ===
insert in the middle of a 365-element list: 0.096 microseconds -> about 182 references are shifted: negligible
with 365,000 elements a mid-list insert shifts ~182,000 references (see table above)
bisect.insort keeps a (day, mm) list sorted: [(1, 5), (2, 0), (3, 9), (4, 3)]
