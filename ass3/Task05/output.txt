                     alarm minutes=[4, 6]
list comprehensions  valid C=[4.0, 5.5, 9.1, 1.5, 7.9, 2.0]
                     F=[39.2, 41.9, 48.4, 34.7, 46.2, 35.6]
                     alarm minutes=[4, 6]
map/filter + lambda  valid C=[4.0, 5.5, 9.1, 1.5, 7.9, 2.0]
                     F=[39.2, 41.9, 48.4, 34.7, 46.2, 35.6]
                     alarm minutes=[4, 6]
Hand check: readings 99.0 and -60.5 are errors; valid = [4.0, 5.5, 9.1, 1.5, 7.9, 2.0]; outside 2-8 C: 9.1 (minute 4), 1.5 (minute 6) -> alarms [4, 6]
Boundaries 2.0 and 8.0 are inside the safe range; 50 and -50 are valid readings: [3, 4]

=== General form of a list comprehension with a condition ===
[expression  for item in iterable  if condition]   ->  the same as:
  result = []
  for item in iterable:
      if condition:
          result.append(expression)

=== Dictionary and set comprehensions for this problem ===
dictionary comprehension {minute: celsius for valid readings} : {1: 4.0, 2: 5.5, 4: 9.1, 6: 1.5, 7: 7.9, 8: 2.0}
set comprehension {rounded temperature for valid readings}    : [2, 4, 6, 8, 9]

all valid       : valid= 1004 alarms=    4 identical=True
all invalid     : valid=    0 alarms=    0 identical=True
empty           : valid=    0 alarms=    0 identical=True
all three versions identical on every test: True
